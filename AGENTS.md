# Agent Guidance

## Icons

- Use [Rune Icons](https://www.runeicons.com/icons) as the preferred source when a UI icon is needed.
- Export the selected icon as SVG and keep it local in `public/icons/` when it is reused.
- Prefer inline SVG for a one-off icon when it needs a project-specific size or color.
- Keep decorative icons `aria-hidden="true"`; give meaningful icons an accessible label or visible text.
- Do not add an icon package or icon font when a Rune SVG is enough.
- Match the existing paper-and-ink style: simple line icons, restrained sizing, and the current accent color.
