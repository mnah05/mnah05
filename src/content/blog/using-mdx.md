This theme comes with [react-markdown](https://github.com/remarkjs/react-markdown) and [remark-gfm](https://github.com/remarkjs/remark-gfm) installed and configured for rendering Markdown content. If you prefer not to use them, you can disable support by removing the packages.

## Why Markdown?

Markdown is a special flavor of plain text that supports headings, lists, tables, blockquotes, and code blocks. Combined with a renderer like `react-markdown`, this unlocks the ability to author content quickly while keeping it consistent with your React UI.

If you have existing content authored in Markdown, this setup will hopefully make migrating to React a breeze.
