"Hello, World!" is often the first program people write. It is a tiny program, but it teaches an important lesson: even one line of output requires a language, a toolchain, and a way to run the code.

In a time when AI can generate code in seconds, writing and running a small program yourself is still valuable. It helps you understand what the code does and gives you the confidence to build more.

Here are a few versions I enjoy.

## Python

```python
print("Hello, World!")
```

## Go

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, World!")
}
```

## TypeScript

```ts
console.log("Hello, World!");
```

## Lua

```lua
print("Hello, World!")
```

## Bash

```bash
echo "Hello, World!"
```

## C

```c
#include <stdio.h>

int main(void) {
	printf("Hello, World!\n");
	return 0;
}
```
